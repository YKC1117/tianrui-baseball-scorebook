# 天睿教育棒球隊｜場邊紀錄系統 v1.2.0

## 這次更新

- 手機場邊額外加入「賽中換人／守位」「操作紀錄」「圖片與備份」快速入口。
- 完整調整視覺層級與行動裝置操作：首頁、固定底部功能列、卡片化欄位、簡化開賽流程。
- 支援單筆新增或一次貼上多行名單（背號＋姓名），也能匯出／匯入。
- **全隊球員名冊**（姓名／背號）獨立保存，只建立一次；可修改、新增、移除、匯出與還原名冊 JSON。
- **本週出賽勾選**：從球隊名冊選出到場球員，勾選人數不限 9 人。
- **先發九棒／守備排陣**：初始順序會自動補滿 9 人，可交換球員、調整棒次、切換守備位置；避免同一名球員重複站位。
- **板凳名單**：勾選超過 9 人的球員自動成為替補；建立比賽後可從賽中換人加入打序。
- 使用現有 Tianrui_B_Transparent.png 隊徽，沒有重新繪圖。
- **比賽紀錄沿用 v1.1.1**：比分 1–9 局、時間到提前結束、進退場、二次登板分次/合併、PNG/CSV/JSON 匯出。

## 使用流程

1. 首次有網路進入 GitHub Pages 網站，進入「球員名單」，逐一建立全隊球員及背號。
2. 點「本週出賽」，輸入日期、對手、主客隊，勾選到場人員。
3. 九位先發自動帶入，可修改 1–9 棒順序與守備；多出來的名單為板凳。
4. 確認後「開始紀錄」，先發陣容複製為**這一場**的快照，不會回頭改掉球隊名冊。
5. 投手、打者重返或換守位在比賽的「賽中換人」調整。
6. 比賽後匯出本場 JSON 與 PNG；全隊名冊另外匯出一份 JSON。

## 注意

- 使用 localStorage 保留本機比賽與名冊，未提供雲端、登入及多裝置同步。
- 更新程式不主動清除既有比賽紀錄；舊資料保持原狀，新全隊名冊初始為空，不會拿過去預設假球員填入。
- GitHub Pages 首次開啟需要網路。**一定要先在手機飛航模式驗證離線再帶去球場。**
- 瀏覽器清除網站資料可能使名冊與比賽全部遺失。JSON 備份不可省略。
- 此版尚需真實比賽及 iOS/Android 裝置驗收後才可宣稱正式版。
