# 天睿教育棒球隊｜單場棒球紀錄系統

**版本：v1.1.0 離線候選版（未完成正式球賽驗收）**

以手機／平板場邊記錄為主，固定 9 人打序，允許換人、重返原守位與投手二次登板。支援主客隊 1～9 局比分與 R/H/E、單場投打守跑數據、當日投手分次登板與合併統計、PNG 圖片與 CSV/JSON 匯出。無帳號、無雲端資料庫，不包含整季統計。

## 使用

1. 首次須**有網路**開啟 GitHub Pages 的 HTTPS 網址，等待網站資源載入完成後，加入手機／平板主畫面。
2. **務必實測飛航模式可重新開啟**且可建立／操作模擬比賽，通過後才能攜帶到沒有網路的球場。
3. 每場比賽後匯出 **JSON 備份**，並另存 PNG 成績圖。不要僅保存圖片，圖片無法還原逐筆資料。
4. Windows 可直接雙擊 `index.html` 在瀏覽器使用，但以檔案模式開啟時不能保證 PWA Service Worker 運作。

## GitHub Pages 部署

建立獨立**公開** repository，例如 `tianrui-baseball-scorebook`，將本資料夾全部檔案放在 repository 根目錄。到 `Settings > Pages > Build and deployment`，選 `Deploy from a branch`、`main`、`/(root)` 並儲存。正式網址格式為 `https://<使用者帳號>.github.io/tianrui-baseball-scorebook/`。

> GitHub Pages 公開網站的原始碼可供他人檢視。請勿上傳真實球員個資、測試比賽 JSON、帳密、API 金鑰或其他敏感資料。正式比賽資料只儲存在使用者瀏覽器本機，並由使用者自行匯出備份。

## 重要限制

- 本系統屬候選版，尚未以天睿球隊的真實賽事完整驗收。
- 離線可用依首次安裝／快取是否成功及瀏覽器儲存政策而定；勿將本機儲存視為永久備份。
- 不支援跨裝置即時同步。同一場請由**一台主記錄裝置**負責。
- 特殊跑壘、自責分（ER）、守備刺殺與助殺（PO/A）仍須由紀錄員判定、補登。
- 單場 ERA 依 9 局制換算，不要求投滿 9 局；投球局數以實際出局數計算，2.2 + 2.0 = 4.2。
- 同名投手的再次登板會建立新登板段，可切換「分次登板／當日合併」。
- 本版不保證完全符合正式棒球賽事裁判紀錄判決，尤其未完成打席中途換投的 BF 歸屬。
- 介面目前採示意圖示，**尚未內嵌天睿正式 Logo**。後續須以已核定透明 PNG 素材替換。

## 版本驗證狀態

- HTML 與內嵌 JavaScript 已通過語法檢查。
- 自動化瀏覽器測試腳本已有準備，但本執行環境限制本地 loopback 瀏覽器連線，**本輪無法取得瀏覽器端到端 PASS**。
- 比賽當天正式使用前，請先用一場模擬比賽驗證計分、換投、二次登板、退場重返、匯出／還原與無網路重新開啟。
