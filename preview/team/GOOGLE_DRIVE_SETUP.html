Google Drive 一次性網頁設定

不需安裝程式、執行指令、設定 Firebase 或綁信用卡。只用球隊專用的免費 Google Cloud 專案及既有 Google 帳號；不要選公司專案。本站目前尚未取得你的 OAuth 用戶端或共用資料夾，沒有宣稱已連接。

  1. 在 Google Cloud Console 建立或選取球隊專用專案，不開啟計費。到「API 和服務 → 程式庫」啟用 Google Drive API 與 Google Picker API。複製專案首頁的專案編號（數字）。
  2. 到「Google Auth Platform」設定應用程式名稱、聯絡 email 與 Audience（個人 Gmail 使用 External）。資料存取只加入 https://www.googleapis.com/auth/drive.file。若仍在 Testing，把要試用的 Google 帳號加入 Test users。正式給全隊使用前，依 Google 主控台要求完成發布／必要審查；不保證測試用戶設定就是正式授權。
  3. 建立 OAuth 用戶端：類型選網頁應用程式，已授權 JavaScript 來源填 https://ykc1117.github.io（沒有路徑、沒有斜線結尾）。本程式用 Google 官方瀏覽器 token model，不需填重新導向 URI。複製用戶端 ID；不要提供 client secret。
  4. 建立 Picker 的公開 API 金鑰。應用程式限制選「網站」，HTTP referrer 填 https://ykc1117.github.io/*；API 限制只選 Google Picker API（依 Google 控制台的 API 名稱）。將用戶端 ID、專案編號及這個公開金鑰貼進天睿網站的「Google 連線設定」。這些是公開識別，沒有 Google 密碼或 OAuth token；不需下任何指令。也可只把這三個公開值提供工程套入同一固定入口，之後球友不需另建專案或填三欄。不要提供密碼、token 或 client secret。
  5. 在 Google Drive 建立天睿棒球紀錄資料夾，分享給指定球友的 Google 帳號：紀錄者設編輯者、只看資料者設檢視者，「一般存取權」保持限制。回到天睿網頁按「連接 Google Drive」，只在 Google 官方視窗登入及授權，選擇此資料夾。首次空白資料夾由擁有者按「建立天睿入口」，網站會自行建立子目錄。球友授權後選同一資料夾。

每次重新開啟網站，Google 存取 token 不會從儲存空間還原；按連接重新授權即可。本機快取與離線草稿仍保留。Google 密碼只輸入 Google 官方視窗，絕不貼入本站、聊天或 GitHub。

已有資料卻顯示空白？

drive.file 是逐檔授權，選取資料夾不會遞迴授權所有子檔案。網站只讀取此應用程式已建立或你明確用 Picker 選過的 JSON。若提示子資料夾不可見，先補選 games、backups、claims，再用「授權既有資料檔」選取入口 tianrui-team.json 及相關版本檔；不要把它當空白隊伍重新建立。跨帳號 Picker／共用子檔案的真實授權仍須實際驗收，不能用模擬測試當成 Google 已核准。

共同使用方式

同一時間只安排一個裝置記分，其餘查看並按「重新讀取」。紀錄前填姓名；每 30 秒嘗試儲存，也可按「儲存到 Drive」。離線只保存本機草稿；續連先核對版本，租約到期需重新接手。有衝突就保留本機與雲端版本，先下載備份再決定採用哪份。

Google Drive API v3 沒有在本實作依賴的可靠原子 CAS。本網站使用新增、不覆寫的版本檔與可偵測的分支；裝置紀錄權只是協調提示，不是資料庫交易鎖。不支援多人同時記分；直接在 Drive 手動修改、刪檔或繞過網頁的編輯者不能被本程式阻止。權限撤銷不能收回已下載到其他裝置的資料。

檔案在你指定的共用資料夾內：tianrui-team.json、games/（單場各版）、backups/（名冊、賽程、排陣各版及完整備份）、claims/（裝置協調紀錄）。網站沿版本鏈取得最新版；多個分支會停止儲存並要求處理。版本檔含完整 JSON；請保留舊版以利恢復。使用 Google 免費 Drive 儲存配額，滿額時停止儲存並保留本機草稿，沒有自動升級或付費備份。
